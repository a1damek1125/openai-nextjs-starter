# Finalis AI — Implementation Backlog (Sprints 0–10)

> **Status**: execution backlog derived from the audit in `34-production-readiness-matrix.md`.
> **Supersession**: this backlog **supersedes the 90-day sprint plan in
> `17-engineering-task-breakdown.md` for execution purposes**. Doc 17 remains the canonical
> source of epics, task IDs, and acceptance-criteria language; every task below cross-references
> its doc-17 ID as `⇐ 17:<ID>`. Where the two disagree on sequencing, this document wins.
> **Starting point**: zero application code. The scaffold (in progress on
> `claude/finalis-ai-enterprise-e2e-autofix`) pre-builds parts of S1 (state machine, scoring
> functions, completion-loop simulation, one E2E test); S1 tasks absorb and harden it rather
> than rewrite it.
>
> **Path conventions**: unprefixed paths are the Python `core` service (new top-level `core/`
> directory or separate repo — decide in S0.1). `web:` prefixes paths in this Next.js repo.
> Sprints are 2 weeks. Each task lists: objective · files/modules · dependencies · acceptance
> criteria (AC) · tests · risks.

## Sprint 1 — Case Graph, state machine, core API

**Goal**: the durable spine — every case lives in the 17-state machine with audit and a REST surface. Absorbs the scaffold branch.

- **S1.1 Core-entity migrations** (⇐ 17: B1–B4 subset for MVP slice) — `BusinessProfile`, `IndustryPlaybook`, `Case`, `Party`, `CasePartyRole`, `Conversation`, `Message`, `MissingItem`, `Promise`, `Action`, `Task`. Files: `migrations/versions/0001_tenant_root.py`, `0002_case_core.py`, `0003_workflow.py`, `finalis/models/*.py` (SQLAlchemy). Deps: S0.4 migration gate. AC: `Case.status` enum 1:1 with `03` §1 (all 17 states); all tables carry `tenant_id`; indexes per `04`. Tests: `tests/test_migrations.py` (upgrade/downgrade), enum-parity test against a literal list. Risks: doc-04 field drift — parity tests are the guard.
- **S1.2 State machine engine** (⇐ 17: C1; scaffold: adopt `finalis/state_machine.py`) — transition table from `03` §4 as data, `transition(case, event, actor, reason, evidence_refs)` API rejecting illegal moves. Files: `finalis/state_machine.py`, `finalis/states.py`. Deps: S1.1. AC: illegal transition raises `IllegalTransition`; legal one returns new state + audit payload; table 1:1 with `03` §4. Tests: `tests/test_state_machine.py` — hypothesis property test (only whitelisted edges ever succeed), exhaustive 17×17 matrix check. Risks: scaffold divergence from `03` — reconcile against doc, not scaffold.
- **S1.3 Global invariants + AuditEvent chain** (⇐ 17: C2, B5) — active case must hold non-null `next_best_action` + `due_at`; every transition writes `AuditEvent{from,to,actor,reason,evidence_refs}` with `hash_prev`. Files: `finalis/invariants.py`, `finalis/audit.py`, `migrations/versions/0004_audit_event.py`. Deps: S1.2. AC: leaving a case active without a next action fails loudly; chain verifiable end-to-end; insert-only enforced (DB trigger). Tests: `tests/test_invariants.py`, `tests/test_audit_chain.py` (tamper → verification failure). Risks: hash-chain write contention — single-writer per case via row lock.
- **S1.4 Evidence + graph edges** (⇐ 17: B3, B6) — `EvidenceReference` polymorphic entity, `graph_edges` typed edge table, basic recursive-CTE blocker query. Files: `migrations/versions/0005_evidence_graph.py`, `finalis/models/evidence.py`, `finalis/graph.py`. Deps: S1.1. AC: edge insert for all `edge_type`s in `04`; "what blocks this quote?" returns correct set on a seeded case (⇐ 17:B7 first cut). Tests: `tests/test_graph_traversal.py` on seeded fixture case. Risks: premature graph generality — implement only the blocker query now.
- **S1.5 Scoring layer v1** (⇐ 17: S-LEAD, S-MIS, S-STUCK; scaffold: adopt scoring module) — pure deterministic functions with weight-version stamping and input-vector persistence. Files: `finalis/scoring/lead.py`, `finalis/scoring/mis.py`, `finalis/scoring/stuck.py`, `finalis/scoring/weights.py`. Deps: S1.3 (audit persistence). AC: bands Hot ≥70/Warm/Cool/Cold; cold-start `R=0.5` + `low_confidence` flag; recompute from stored `AuditEvent` reproduces value bit-for-bit; thresholds read from `BusinessProfile.thresholds`, never hard-coded. Tests: `tests/test_scoring.py` golden input→output vectors + `θ ± ε` boundary tests + reproducibility replay. Risks: weight churn — `weights_version` from day one.
- **S1.6 Core REST API v1** (⇐ 17: A5/A6 seam, `22` API model) — CRUD + transition endpoints. Files: `app/api/v1/cases.py`, `app/api/v1/parties.py`, `app/api/v1/audit.py`, `app/schemas/*.py` (Pydantic). Deps: S1.2–S1.5. AC: `POST /api/v1/cases`, `GET /cases/{id}`, `POST /cases/{id}/transitions` (202 on accepted, 403/409 semantics per `22`); OpenAPI published. Tests: `tests/test_api_cases.py` (httpx), contract-shape snapshot. Risks: API drift vs. `22` — snapshot test pins it.
- **S1.7 Tenant-scoped repository layer** (⇐ 17: B10, X.1 baseline) — mandatory `tenant_id` on every query; RLS policies. Files: `finalis/repo.py`, `migrations/versions/0006_rls.py`. Deps: S1.1. AC: unscoped query fails a guard test; tenant A cannot read tenant B through the API. Tests: `tests/test_tenancy.py` isolation suite. Risks: RLS + connection pooling interplay — set `app.tenant_id` GUC per request.

## Sprint 3 — Follow-up Worker, Promise Tracker, Missing-Info Hunter

**Goal**: the completion loop — no case silently dropped; hard guarantees unbreakable.

- **S3.1 Durable scheduler** (⇐ 17: A4) — Postgres-backed job queue (APScheduler/pg_cron style per `09` MVP note) with restart survival. Files: `finalis/scheduler.py`, `migrations/versions/0008_jobs.py`. Deps: S1.1. AC: job scheduled 72h out survives service restart. Tests: `tests/test_scheduler.py` with clock injection; kill/restart integration test. Risks: building half of Temporal — keep API minimal (`schedule_at`, `cancel`, idempotency key).
- **S3.2 FollowUpSequence engine + cadence presets** (⇐ 17: I1, I5) — steps, quiet_hours, max_attempts, min_interval, `active_step_index`; presets `+24h/+48h/+72h` (missing-info) and `+24h/+72h/+7d→RECOVERY_LATER` (post-offer). Files: `finalis/workers/followup.py`, `migrations/versions/0009_followup_sequence.py`. Deps: S3.1. AC: cadence advances step-by-step; exhausted → `RECOVERY_LATER` with `wake_at`. Tests: `tests/test_followup.py` time-travel tests over `36` §10 fixtures. Risks: timezone bugs — all schedule math in tenant tz, tested at DST boundaries.
- **S3.3 Hard guarantees + STOP/opt-out** (⇐ 17: I3, C12) — quiet hours, opt-outs, STOP → `ABANDONED`/`LOST` + permanent suppression, min interval, max attempts, one consolidated ask; guarantees evaluated *after* scoring, can only veto. Files: `finalis/guards.py`, `finalis/workers/followup.py`. Deps: S3.2. AC: no outbound schedulable to a STOPped party ever; quiet-hours attempt blocked regardless of score. Tests: `tests/test_guards.py` adversarial suite (score=100 still blocked); suppression survives case re-open. Risks: guard bypass via manual send path — S2.4 path routes through the same guard.
- **S3.4 FollowUpPriority + channel selection** (⇐ 17: S-FUP, I4) — `LeadScore·TimeDecay·IntentSignal − AnnoyanceRisk`; playbook default channel order, learned per-party preference later (stub the interface). Files: `finalis/scoring/followup_priority.py`. Deps: S1.5, S3.2. AC: channel+timing chosen by score; guarantees never violated. Tests: golden vectors in `tests/test_scoring.py`; property test guards ∘ priority. Risks: Deal Memory dependency — defer learned preference to S9+, keep default order.
- **S3.5 Promise Tracker + breach scoring/routing** (⇐ 17: I6–I8, S-BREACH) — extract `Promise` rows (any party) from messages/transcripts; `Importance·Delay·DependencyImpact`; client breach → nudge, company-side → owner alert. Files: `finalis/workers/promises.py`, `finalis/scoring/breach.py`. Deps: S2.2 (LLM client), S3.1. AC: overdue "send signed contract" outscores overdue "send a photo"; routing per party role. Tests: `tests/test_promises.py` on golden transcripts (`36` §2); S-BREACH golden vectors; routing integration test. Risks: extraction recall — measured in S9, seeded fixtures now.
- **S3.6 Missing-Information Hunter** (⇐ 17: I9) — re-evaluate `MissingItem`s per event; `MIS_normalized ≥ θ_mis` or any missing `blocks_quote` → exactly one consolidated example-bearing request; `received` marking; `QUOTE_PREPARATION` unreachable with open `blocks_quote`. Files: `finalis/workers/missing_info.py`. Deps: S2.3, S3.3. AC/tests: state-gate test + consolidation test in `tests/test_missing_info.py`; recall target formalized in S9. Risks: nagging loops — max-attempts guard covers.
- **S3.7 Nightly stuck sweep + RECOVERY_LATER wake** (⇐ 17: C8, I12) — recompute LeadScore/MIS/StuckScore/PromiseBreachScore (EscalationScore = hard rules only until S8+); invariant check; enqueue NBA; park exhausted; wake due parked cases with contextual opener. Files: `finalis/sweep.py`, scheduler job registration. Deps: S3.1–S3.6, S1.5. AC: sweep on seeded fixtures produces expected transitions + queued actions (⇐ 17:C8 AC verbatim). Tests: `tests/test_sweep.py` time-travel over `36` §11 stuck fixtures. Risks: sweep runtime at scale — irrelevant at 0 tenants; add duration metric now (X.3).
- **S3.8 Autonomy levels + HITL interrupt (v1)** (⇐ 17: M1, M2, C3 hard-rules-only) — per-action-type levels from `BusinessProfile.autonomy_defaults`; above level → `HumanApproval`; hard rule (STOP, safety keyword, legal doc) → `HUMAN_REVIEW_REQUIRED`, autonomy capped at L2, outbound frozen.
